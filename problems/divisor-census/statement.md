# Divisor Census

A mathematician is asked $q$ questions of the form "how many positive integers divide $x$?" (both $1$ and $x$ count).

Answer them all.

## Input

The first line contains $q$ ($1 \le q \le 5 \cdot 10^4$). The second line contains $q$ integers $x_1, \dots, x_q$ ($1 \le x_j \le 5 \cdot 10^5$).

## Output

Print $q$ integers separated by spaces: the number of divisors of each $x_j$.

## Notes

In the first example $12$ has divisors $1, 2, 3, 4, 6, 12$ (six of them), $7$ is prime (two divisors) and $1$ has just one.
